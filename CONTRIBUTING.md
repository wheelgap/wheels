# Contributing to wheelgap/wheels

Thanks for helping! Everything you need is in [AGENTS.md](AGENTS.md): how to run the tests, what each script does, the house rules, and how to claim an issue (comment on it and it's yours for 18 hours).

Good places to start:

- Issues labelled [`good first issue`](https://github.com/wheelgap/wheels/labels/good%20first%20issue) in this repo.
- The [Start here](https://github.com/wheelgap/wheelgap/issues/382) issue, which lists the open issues across all three wheelgap repos.

AI-assisted PRs are welcome: say which tool helped in the PR description.
